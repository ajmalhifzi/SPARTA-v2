# Design direction

Product mode: Operate. User-pinned brief: modern, formal, school-oriented, lightweight, responsive and accessible. These constraints override optional concept approval workflows and marketing conventions. Applied skills: impeccable and design-taste-frontend (the installed counterpart of the requested design-taste-skill).

Grounded directions considered: registrar forms, technical department handbook, faculty publication, library catalogue, examination stationery, workshop record sheet, student-services portal. The concept seed selected position 3; faculty publication is the retained direction. A disciplined publication index and readable writing surface carry the long document. The brief pins institutional restraint; decorative map/performative challenger worlds are outside that constraint. No generated imagery is required for a factual document workspace.

Palette: navy #142f42, paper white, cool reading ground #f2f5f6, restrained blue selection. Amber is reserved for source-audit messages; green for actual save feedback. IBM Plex Sans is self-hosted for UI; Source Serif 4 appears only on document covers/login identity, not form labels. One 4px radius on controls, 3px on small status labels, no ornamental card system or shadows.

First viewport: document identity, current project, fixed printed-document order and immediately usable writing surface. Signature interaction: thirteen real numbered source sections, each addressable by URL, with a dedicated editor. Other pages use the same field/action vocabulary. Mobile collapses the outer navigation and turns the section index into a horizontal strip; tables preserve headers in a scrollable labelled region. Print removes navigation and exposes saved narrative text without textarea clipping.

Risk: without original images the covers cannot claim exact physical fidelity. The preview says so. Blue/navy is an interface choice, not a claimed official KVSP1 brand palette. Design dials: variance 3, motion 2, density 5. Light form surfaces are chosen for daytime reading and matching printed documents. Motion is only 160ms interaction feedback, with reduced-motion support.
